擦键盘和触摸板时，误触会把一个很简单的动作变得麻烦：字符乱入、光标移动、窗口突然切换。BKCleanHelper 把这个场景做成了一个专用小工具，临时暂停输入，留出 60 秒清洁时间，到时自动恢复。

![BKCleanHelper 清洁遮罩界面示意图](/images/projects/clean-helper.svg)

## 清洁前准备，结束后恢复

应用常驻 macOS 菜单栏。开始清洁前有准备时间，放开按键后进入清洁界面；内置键盘、触摸板以及外接键鼠的输入会被统一暂停。

需要提前结束时，同时按住 `Control + Option + Command + U` 两秒即可。应用也提供无需授权的界面预览，用于了解显示效果；预览不会屏蔽实际输入。

## 恢复机制是核心部分

暂停输入的工具必须认真处理结束条件。BKCleanHelper 把输入拦截与计时交给独立子进程，避免只依赖主界面的倒计时。通信与心跳检查、截止时间和看门狗共同参与恢复流程。

按照仓库设计，主程序退出、通信断开、锁屏、睡眠或切换用户等情况会触发解除。这个实现关注的是清洁期间的短暂控制，以及异常情况下尽快交还输入，而不只是遮住屏幕。

## 原生、轻量、完全本地

项目使用 Swift 与 AppKit，支持 macOS 13 及以上，使用系统字体、SF Symbols 和系统明暗外观。不联网、不记录输入，也不安装内核驱动。

正式清洁需要辅助功能和输入监控两项权限，分别服务于输入事件拦截与监听。电源键、Touch ID 等系统级输入无法按普通键鼠事件处理，部分手势也受设备与系统行为影响，具体边界已在 README 中说明。

## 体验入口

可以先预览界面，确认操作方式后，再按照仓库说明安装到“应用程序”并授权。真正开始清洁前，记住提前结束的组合键，操作会更从容。
