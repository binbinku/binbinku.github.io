手机运行一个应用时，单独看 CPU、内存或帧率，很难把变化放在同一条时间线上。BKDeviceMonitor 是一个本地运行的 Android 性能监测桌面应用，把负载、趋势、应用状态和设备信息集中展示，方便观察，也方便保留一次测试的结果。

![BKDeviceMonitor 性能总览](/images/projects/device-monitor.jpg)

## 一根数据线连接设备

应用通过 USB / ADB 连接手机，需要开启 USB 调试并在手机上授权。准备好依赖与 ADB 后，采集和分析可以离线完成，无需 Root、Shizuku 或额外安装手机端应用。

桌面模式基于 Electron，通过受限 IPC 调用本地采集引擎，无需单独启动 HTTP 后端。源码也保留了可选的本机网页入口，两种入口共用界面与采集能力。

## 看趋势，也看指标的来源

性能页包括整机与逐核 CPU、频率、GPU、内存、电池和温控等信息。跟随前台应用或选择运行中的应用后，还能查看目标主进程的 CPU、内存，以及设备支持时的帧率、帧间隔与卡顿数据。

这些读数需要结合采集口径理解。应用 CPU 与内存只统计主进程；屏幕刷新率不等于应用 FPS；电池温度也不能直接当作 CPU 温度。GPU、Perfetto、温度等能力依赖系统版本、厂商接口与权限，不可读的指标会显示 `—`。

硬件页则把设备实读与匹配型号的官方规格分开标注，避免把规格表中的参数当成当前运行状态。

## 从实时观察到测试记录

趋势支持不同时间范围和悬停读数，测试会话可以记录峰值与汇总，并导出 CSV 趋势、JSON 报告及硬件配置。趋势和会话主要保留在本次运行的内存中，退出应用前需要导出想留下的结果。

文档中的 v1.4.0 还提供独立 APK 安装，以及共享存储的只读浏览、多选和文件夹下载。文件下载展示实际字节进度，适合把手机上的测试素材取回电脑。

## 适合怎样使用

可以先连接设备、观察空闲状态，再打开目标应用对照趋势；需要复查时，开启测试会话并在结束后导出报告。跨设备比较之前，应先确认两台手机实际可读的指标与统计口径。
