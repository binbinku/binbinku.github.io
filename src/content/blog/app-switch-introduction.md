同时打开几个 VS Code 项目，再加上浏览器和终端时，切换到应用只是第一步，还得找到应用里的那个窗口。BKAppSwitch 是一个原生 macOS 菜单栏工具，把自己选定的应用窗口放进同一个列表，直接选择目标窗口。

![BKAppSwitch 的窗口切换列表，使用内置演示数据](/images/projects/app-switch.png)

## 按住 Option，选择，再松开

基本操作是按住 `Option`、按下 `Tab` 调出并移动选择，松开 `Option` 后激活目标窗口。还支持反向选择、方向键、鼠标点击，以及 `Esc` 取消。最小化窗口会带有标记，选择后可以恢复并激活。

参与切换的应用可以自行配置，默认包含 VS Code，也可以添加其他 `.app`，临时停用或移除。这样列表可以只保留当前工作需要的工具。

## 固定顺序，减少找窗口的成本

列表中的已有窗口在运行期间保持相对顺序，新窗口追加到末尾。切换不会反复重排整张列表，常用窗口的位置因此更容易记住。最近焦点影响初始选择，而不是把窗口顺序不断洗牌。

对于 VS Code，工具会尝试从标题中提取项目名称，同时保留原始标题。识别方式可以调整；这依赖窗口标题本身，不需要读取项目文件。

## 原生实现与权限边界

项目使用 Swift、SwiftUI 与 AppKit，没有第三方依赖。窗口发现与激活结合 macOS 辅助功能接口和应用原生“窗口”菜单，因此需要辅助功能权限，无需输入监控或屏幕录制权限。

工具在本地运行，不发送窗口标题，也不需要账号。不同应用对窗口接口的支持并不完全一致，跨桌面或全屏窗口的发现与激活效果需要结合具体应用确认。

## 开始使用

系统要求为 macOS 13 或更新版本。可以先通过演示界面了解列表，再按 README 完成构建或安装与授权。仓库打包脚本生成 Apple 芯片版本，Intel Mac 需要从源码构建验证。
